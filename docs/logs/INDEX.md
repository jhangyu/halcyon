content (paths, conclusions, decisions) is later superseded; supersession is itself recorded
as a new log, not an edit to the old one. This index is regenerated by hand whenever logs are
added or removed; it is not auto-generated.

Date folders are listed newest first. Within each folder, files are listed alphabetically.
Each row is a one-line purpose derived from that file's own header/opening lines.
